# Claude review entry point

This repository has a queued independent review in `review/claude/REQUEST.md`.
Read that request and `CLAIMS.md` first. Review both the formal mathematics
and the narrative descriptions. Existing build receipts and prior assistant
conclusions are evidence to examine, not conclusions to adopt.

Preserve the candidate while reviewing. Write findings, any proposed prose,
and new check files in a fresh subdirectory of `review/claude/runs/`.
The current task is review and preparation; publication and Palomar
submission are later steps. Record what was actually run, the exact source
identity and toolchain, and anything that could not be checked.
